# Notebooks

Thin notebooks that satisfy the brief's requested folder layout and give
an interactive place to experiment. Each simply imports and runs the
corresponding production training script in `training/`, so the "real"
logic lives in one place.

- 01_image_classifier_training.ipynb -> training/train_product_classifier.py
- 02_face_recognition_setup.ipynb -> training/train_face_db.py
- 03_sentiment_model_training.ipynb -> training/train_sentiment_model.py
